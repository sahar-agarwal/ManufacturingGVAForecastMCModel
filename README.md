# ManufacturingGVAForecastMCModel
Forecasting Manufacturing GVA across short-term, medium-term and long-term horizons, making use of ARIMAX forecasting and MC simulated data for medium and long term forecast, accounting for variables like REER, Bank Credit, IIP, WPI, Govt. CapEx, Exports, Historical GVA and exogenous COVID-19 shock.
